# Исправление ошибки Redeclaration в PoolTajectory 0.2.1

В предыдущем проекте исходники лежали в каталоге `app/src/main/java/com/pooltrajectoy/br` (ошибка в имени каталога). В версии 0.2.0 они также были добавлены в правильный каталог `app/src/main/java/com/pooltrajectory/br`. Если распаковать ZIP поверх старого проекта, старые файлы не удаляются и Kotlin компилирует обе копии классов.

## Что исправлено

1. В ZIP 0.2.1 оставлен только один каталог исходников: `com/pooltrajectory/br`.
2. В GitHub Actions добавлен шаг, который удаляет старый каталог `app/src/main/java/com/pooltrajectoy` перед сборкой.
3. В `VisionProcessor.kt` исправлен тип аргумента `threshold` в вызове OpenCV `Imgproc.HoughLinesP`: вместо `Double` теперь передаётся `Int`.
4. Версия приложения повышена до `0.2.1` (versionCode 3).

## Важно при обновлении существующего GitHub-репозитория

Если обновляете файлы вручную, удалите каталог `app/src/main/java/com/pooltrajectoy` целиком. Оставьте только `app/src/main/java/com/pooltrajectory/br`. Не копируйте новую папку поверх старой без удаления старой.

Workflow GitHub Actions теперь чистит старый каталог автоматически, но локальную копию Android Studio также нужно очистить вручную.

## Проверка

Проверены структура ZIP, единственность объявлений основных Kotlin-классов, соответствие `package` каталогу, отсутствие ссылок на `cueLostFrames` в новой версии и исправление аргумента `HoughLinesP`. Полную Android-сборку в текущей среде выполнить не удалось: здесь нет Android SDK/Gradle и сетевой доступ к загрузке зависимостей недоступен. Поэтому APK не заявляется как собранный или протестированный.
