# Pool Assistant — Android starter

Стартовый каркас Android-приложения для исследовательского/тренировочного анализа бильярдных изображений.

## Модули
- `capture`: точка интеграции Android MediaProjection (пока интерфейс).
- `vision`: модели координат и интерфейс распознавания.
- `physics`: геометрия столкновений и отражения от бортов.
- `ui`: простая главная Activity.

## Сборка
Откройте папку проекта в Android Studio с Android SDK установленным.
Рекомендуется JDK 17 и Android Gradle Plugin 8.5+.
Это исходный каркас, не готовый APK. Для сборки потребуется Gradle sync.
