# PoolTrajectory BR — Android source project

Учебный прототип прозрачного оверлея для визуального анализа 2D-бильярда.

## Требования
- Android Studio с Android SDK Platform 35
- JDK 17
- Gradle 8.9+ (Android Gradle Plugin 8.7.3)
- Android 8.0+ (API 26+)

## Сборка APK
1. Распакуйте архив.
2. Откройте папку `PoolTrajectoryBR` в Android Studio.
3. Дождитесь синхронизации Gradle и загрузки OpenCV AAR.
4. Подключите Android-телефон и включите USB debugging либо выберите эмулятор.
5. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Из командной строки из корня проекта:
```bash
gradle assembleDebug
```

## Запуск
1. Установите APK.
2. Откройте PoolTrajectory BR.
3. Нажмите «Разрешить оверлей» и выдайте системное разрешение.
4. Нажмите «Начать захват экрана» и подтвердите системный диалог Android.
5. Перейдите в игру. Для остановки вернитесь в приложение и нажмите «Остановить» либо остановите уведомление/службу.

## Ограничения прототипа
- Android показывает системное подтверждение для каждой новой сессии MediaProjection.
- В некоторых приложениях/экранах Android или самой игры захват может быть пустым/защищенным.
- OpenCV-детекция настроена на типичные зеленые/синие поля и нуждается в калибровке под конкретный экран.
- Направление кия пока является эвристикой по прямым линиям на изображении. Если игра рисует прицельную линию иначе или не рисует ее, направление может не определиться либо потребовать калибровки.
- Геометрия физики использует упрощенную модель идеальных шаров и прямых бортов; вращение, сила удара, трение и эффекты не моделируются.
- Это исходный проект для сборки и тестирования, не предварительно собранный и не проверенный на устройстве APK.

## Разрешения и приватность
Приложение использует только системный MediaProjection и разрешение отображения поверх других приложений. Кадры обрабатываются локально на устройстве и не отправляются на сервер.
