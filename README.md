# PoolTajectory — Android project

Android-приложение для визуального анализа 8 Ball Pool через системный захват экрана Android. Проект использует MediaProjection и OpenCV; он не читает память процесса игры и не меняет игровые файлы.

## Что изменено в версии 0.2.0

- Детектор битка переведён с поиска максимума по интегральному изображению на фильтрацию контуров по размеру, пропорциям, круглости и яркости.
- Ослаблен порог белой маски, а морфологическое ядро уменьшено: старая настройка могла разрушать белый шар и оставлять только блики.
- Удалено удержание старых координат битка до 12 кадров. Если шар не найден, ложная траектория не строится.
- Добавлено маскирование линий и маркеров предыдущего кадра HUD в рабочих CV-масках, чтобы собственная графика оверлея не становилась ложными объектами при захвате на прошивках, где MediaProjection включает overlay-окна.
- Переработана первая точка сканирования луча: прежний старт слишком далеко от битка мог пропускать близкие цели и смещать точку ghost-ball.
- Исправлена обработка `Bitmap` при захвате экрана: в случае совпадения размеров `createBitmap()` мог вернуть тот же объект, который затем сразу освобождался.
- Системные запросы разрешений теперь показываются последовательно.
- Удалён некорректный атрибут `configChanges` у сервиса; ошибки обработки кадров пишутся в Logcat.
- Исходники перемещены в каталог, соответствующий package `com.pooltrajectory.br`.

## Требования для локальной сборки

- Android Studio с Android SDK Platform 35
- JDK 17
- Gradle 8.9
- Android 8.0 (API 26) или новее на устройстве

Зависимости OpenCV 4.10.0 и AndroidX загружаются Gradle из Maven-репозиториев при синхронизации проекта. В этой копии нет локального Android SDK или готового APK.

## Открытие и сборка

1. Распакуйте архив.
2. В Android Studio выберите **Open** и укажите папку `PoolTajectory-main` (корень, в котором лежат `settings.gradle.kts` и `build.gradle.kts`).
3. Установите JDK 17 и Android SDK Platform 35 в SDK Manager.
4. В настройках Gradle выберите Gradle JDK 17 и Gradle 8.9. Если Android Studio попросит создать/подключить Gradle Wrapper, выберите версию 8.9.
5. Выполните **Sync Project with Gradle Files**.
6. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
7. Debug APK будет создан по пути `app/build/outputs/apk/debug/app-debug.apk`.

Также включён GitHub Actions workflow `.github/workflows/android.yml`: после загрузки проекта в GitHub и включения Actions можно вручную запустить workflow **Build Android APK**. Результат будет доступен как artifact `PoolTajectory-APK`.

## Первый запуск на телефоне

1. Установите APK.
2. Откройте PoolTajectory.
3. Разрешите отображение поверх других приложений.
4. Нажмите **Запустить плавающий HUD** и подтвердите системное разрешение захвата экрана.
5. Перейдите в 8 Ball Pool.
6. Откройте плавающее меню и включите режим калибровки стола. Переместите две зелёные точки к левому верхнему и правому нижнему углам игрового сукна, затем завершите калибровку.
7. Для остановки вернитесь в приложение или нажмите остановку в уведомлении.

## Важные ограничения

- Детекция зависит от масштаба, графики, бликов и качества изображения. Пороговые значения нужно проверить на реальных скриншотах конкретного устройства.
- Перед первым использованием откалибруйте границы стола. Автоматические пропорции — только начальное приближение.
- Направление кия всё ещё определяется эвристически по светлой линии на изображении. Варианты отображения прицела в разных режимах игры могут отличаться.
- Столкновения и отскоки рассчитаны упрощённой 2D-моделью. Вращение, точная сила удара, трение, динамические эффекты и сетевые параметры игры не моделируются.
- Проект не проверен на физическом устройстве в этой среде; перед использованием требуется сборка и тестирование на вашем телефоне.

## Приватность

Кадры обрабатываются локально на устройстве. Приложение не отправляет скриншоты на сервер.
